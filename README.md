# Workbench 日常工具箱

Windows 桌面应用，使用 Electron、Vue 3、TypeScript、Element Plus、Pinia 和 SQLite。

## 功能

- 工具目录、搜索、分类、收藏、最近使用、浅色和深色主题。
- Git 项目添加、检测、移除，本地和远程分支列表、比较基准、合并状态、本地分支切换。
- 获取远程并清理失效引用，批量删除分支、逐项结果与操作记录。
- JSON 代码、结构和对比视图，格式化、压缩、校验、字段增删改、查找替换和差异高亮，保留超大整数精度。
- 文本逐行去重、空白处理、大小写转换、排序、反转、添加行号与前后缀、字符/行/UTF-8 字节统计。
- 秒、毫秒、微秒、纳秒时间戳与日期转换，时区切换、批量转换、日期加减与时间差计算。
- 编码解码：Base64、Base64URL、URL、Unicode 和 HTML 实体，支持 UTF-8、实时转换与反向转换。
- 文本对比：按行或单词/字符高亮差异、忽略空白或大小写、差异跳转和补丁导出。
- JWT 解析：Header、Payload、有效期与生效时间；仅解析，不验证签名或可信性。
- UUID v4/v7、批量随机字符串和密码生成，使用安全随机源。
- 正则表达式：匹配高亮、捕获组、常用模板与替换；独立 Worker 执行，超时自动中断。
- 哈希校验：文本/文件 MD5、SHA-256、SHA-512，支持摘要比对、文件进度和取消。
- JSON 与 YAML 互转，保留大整数；不支持无损转换的小数和循环引用会明确报错。

## 使用

安装 `release/0.1.2/Workbench-Setup-0.1.2.exe`，或直接运行 `release/0.1.2/win-unpacked/Workbench.exe`。

界面采用固定导航与分区滚动：Git 项目列表、分支表格分别滚动，仓库操作栏和表头保持可见；JSON 和文本工具的输入、输出区域也可独立滚动。

Git 功能需要电脑已安装 Git。默认使用 PATH 中的 `git`，也可以在设置中指定 `git.exe`。远程认证沿用已有 Git/SSH 配置；程序不保存密码，不弹出交互式终端，认证失败时会显示 Git 错误。

添加项目只保存仓库根目录。移除项目只移除工具箱记录，不删除任何项目文件。应用数据保存在 Electron 的用户数据目录，可在设置中打开；Windows 通常为 `%APPDATA%/workbench-toolbox`。卸载默认保留数据。

## 分支删除规则

- 当前分支、比较基准、保护规则匹配分支、远程默认分支及其他 worktree 占用分支不能删除。
- `main`、`master`、`develop` 始终保护，初始规则还包含 `release/*`。
- “已合并”表示该分支提交可从所选比较基准到达，不按分支名称或更新时间自动认定无用。
- 未合并分支需要勾选强制删除，并输入项目名；删除远程分支也需要输入项目名。
- 删除前重新读取仓库并比对提交；本地删除通过 Git 引用锁原子比对提交哈希，分支提交变化时拒绝删除，并再次检查 worktree 占用。远程删除会检查服务器实际默认分支，并使用 `--force-with-lease` 拦截尚未获取的服务器变更。无法识别服务器默认分支时阻止远程删除。
- 仓库操作按项目串行执行；其他 Git 客户端仍可能同时修改仓库，操作后应刷新状态。
- 分支提交数在 Git 2.41 及以上版本批量读取；旧版 Git 自动使用按提交去重的兼容查询。
- 首次清理建议先执行“同步远程”。本地和远程分支是独立条目，按实际勾选分别删除。
- 未提交修改时禁止在面板切换分支；不会自动提交、暂存或清理文件。

## 开发

需要 Node.js **22.12 或以上**（建议 24 LTS）、npm 和 Git。安装后的应用自带运行时，不要求用户安装 Node.js。

```bash
npm install
npm run dev
npm run test
npm run build
npm run dist
```

`npm run dev` 自动选择空闲本地端口，并启动桌面窗口。Electron 主进程修改后需重启开发命令。仅预览页面可执行 `npm run dev:web`；网页模式可使用数据工具，本地 Git 功能需桌面版。

```bash
node scripts/smoke.cjs
```

桌面冒烟测试使用临时仓库、临时 SQLite 和模拟的目录选择结果，不操作现有仓库。截图输出至 `output/playwright`。设置 `WORKBENCH_EXE` 可对打包后的可执行程序运行相同测试；设置 `WORKBENCH_WEB_URL` 可额外验证 Edge 中的桌面和移动布局。

运行网页预览后，可执行 `node scripts/smoke-web.cjs` 独立验证工具页面、主题和模拟 Git 接口的删除流程，需要安装 Edge。默认连接 `http://127.0.0.1:5173`，可通过 `WORKBENCH_WEB_URL` 指定地址；截图同样输出至 `output/playwright`。

JSON 数据处理测试可单独运行 `npm run test:json`。`node scripts/smoke-json.cjs` 验证 JSON 编辑、字段操作、导入导出、对比、草稿恢复和多尺寸布局，同样使用 `WORKBENCH_WEB_URL` 指定预览地址。

## JSON 工作台

- 代码编辑：语法高亮、错误定位、行号开关、自动换行、代码折叠、撤销重做、查找替换，支持正则表达式和区分大小写。
- 数据处理：格式化、压缩、校验、递归排序对象键、JSON 字符串转义与反转义；缩进支持 2 空格、4 空格和 Tab。
- 结构编辑：修改字段名称、值和类型，添加对象字段或数组项、删除节点、展开折叠以及复制 JSON Pointer 路径。修改结果保留在结果区，可撤销恢复。
- JSON 对比：两侧可编辑，按差异块高亮并跳转，可标准化格式并选择忽略对象键顺序；数组顺序保留。两侧分别支持导入、复制和下载。
- 文件与草稿：导入 JSON/TXT 文件（上限 20 MB，支持 UTF-8 BOM）、复制和下载结果、交换两侧内容、载入示例；输入和结果在当前会话内恢复，行号和缩进等偏好保存在本机。
- 全部解析、格式化及字段操作均使用无损数字类型，大整数和高精度小数不会通过 JavaScript Number 中转。

## 时间戳工作台

- 单次转换：自动推断时间戳单位，或手动指定秒、毫秒、微秒、纳秒；支持负数、小数和纳秒精度。自动推断依赖位数，历史或远未来时间请手动指定单位。
- 时区与日期：支持 IANA 时区、带偏移的 ISO 日期、UTC 输出和夏令时冲突处理。无偏移日期按所选时区解释，带偏移日期按自身偏移解释。
- 快捷操作：实时秒/毫秒时钟及暂停、常用城市时钟、今日/周/月/年起点和今日/月末最后一纳秒、最近转换及复制。
- 批量转换：每行输入时间戳或日期，最多 1000 行；逐行反馈结果及错误，保留原始行号，可复制或导出文本。修改输入、格式或时区后需重新转换。
- 日期计算：年、月、周、天按所选时区日历计算，月末取目标月最后有效日期；小时等按实际时长计算。时间差保留正负号及纳秒，天数和小时小数最多显示 9 位。
- 时间戳和日期草稿保存在当前会话，时区偏好保存在本机。`npm run test:time` 运行数据测试，`node scripts/smoke-time.cjs` 验证预览界面，预览地址通过 `WORKBENCH_WEB_URL` 指定。

## 扩展工具

六个新增工具均在本机处理数据，不上传输入内容，编辑内容不写入持久存储，刷新或重启后清空。文本文件导入上限 5 MB，文本对比总输入上限 40 万字符，正则输入上限 20 万字符、最多显示 1000 个匹配。`npm run test:tools` 验证编码、JWT、随机数据、文本处理、正则、YAML 和哈希逻辑。

工具元数据登记于 `src/renderer/tools.ts`，页面按模块放入 `src/renderer/components`。需要本地能力时，在 `src/main` 实现，并通过 `src/preload` 和 `src/shared/types.ts` 暴露明确的调用接口。渲染页面无法直接访问 Node.js 或执行任意命令。

## 安装包

使用 electron-builder 和 NSIS 构建 Windows x64 安装包。当前构建未配置代码签名证书，Windows 可能显示未知发布者提示。正式对外发布前应配置签名。
